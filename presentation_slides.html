Giới Thiệu Claude Testing Kit

Là bộ công cụ tối ưu hóa tích hợp sâu vào môi trường làm việc của AI Agent (Antigravity hoặc Claude Code CLI), thiết kế dành riêng cho Manual QA tại Việt Nam.

  • Chuẩn hóa 100% Tiếng Việt: Giao tiếp, làm rõ nghiệp vụ và kết xuất Test Case bằng tiếng Việt tự nhiên, chính xác.
  • Tự động hóa theo Workflow: Trực quan hóa các quy trình phân tích và thiết kế thông qua phím tắt tiện lợi.
  • Cam kết đầu ra chuẩn Jira/Excel: Test cases định dạng bảng markdown gọn gàng, sẵn sàng import lên Xray hay lưu trữ Excel.

Hệ Thống Phím Tắt Lệnh (Slash Commands)

Kích hoạt nhanh các luồng công việc phức tạp chỉ với một ký tự `/` đơn giản.

/analyze_requirement_document Phân tích tài liệu yêu cầu (Jira ticket, User Story) để phát hiện điểm mờ nghiệp vụ.
/generate_manual_testcases_rbt Sinh bộ Test Cases chất lượng cao theo đúng quy trình AI-RBT 6 bước.
/generate_requirements_from_website Tự động quét cấu trúc DOM/giao diện website để viết tài liệu Requirements.
/generate_test_data Sinh dữ liệu test ngẫu nhiên, unique nhưng traceable cho các UI Form hoặc API.
/generate_cross_module_test_plan Thiết kế kịch bản test tích hợp kết hợp nhiều Module nối tiếp.
/generate_combinatorial_test_data Sinh ma trận dữ liệu kết hợp đa chiều (Pairwise/Full Cartesian).
/generate_application_test_plan Khám phá toàn bộ ứng dụng web để sinh test plan tổng thể.
/import_test_results_xray Đẩy kết quả test automation từ local lên Jira/Xray Cloud.

Áp dụng kiểm thử dựa trên rủi ro (Risk-Based Testing) để tối ưu hóa nguồn lực và tăng tối đa độ bao phủ.

💡 Điểm cốt lõi: AI tự phân loại các trường hợp kiểm thử theo độ rủi ro (P0: Chặn luồng nghiệp vụ chính, P1: Ảnh hưởng lớn, P2: Lỗi nhỏ/Giao diện) để ưu tiên thực hiện trước.

Chất Lượng Đầu Ra & Quy Tắc Nghiêm Ngặt

AI Agent tuân thủ bộ quy tắc trong dự án để đảm bảo tài liệu Test Cases luôn đạt chuẩn bàn giao (Definition of Done).

Anti-Patterns (Hành vi bị cấm)

  • Dùng dữ liệu test chung chung như "nhập email hợp lệ".
  • Test Step viết mơ hồ, lặp lại nhiều lần.
  • Gộp validation của nhiều trường vào chung 1 Test Case.
  • Các Test Cases phụ thuộc chéo vào kết quả của nhau.

Đúng Chuẩn Bàn Giao (DoD)

  • Dữ liệu test có giá trị cụ thể, duy nhất và truy vết được (traceable).
  • Từng bước test và expected result đánh số tương ứng (1, 2, 3...).
  • Bao phủ đầy đủ: Happy, Negative, Boundary, Edge Cases.
  • Bảng Markdown sạch sẽ, sẵn sàng import lên Jira/Excel.

Kịch Bản Demo Thực Tế (Live Demo)

Hãy cùng trải nghiệm 3 kịch bản phổ biến nhất của bộ Kit trực tiếp trên IDE:

1. Phân Tích Nghiệp Vụ

Nhập một đoạn tài liệu yêu cầu ngắn -> Chạy /analyze_requirement_document để AI tự phát hiện các điểm mờ nghiệp vụ, yêu cầu làm rõ trước khi viết test.

2. Thiết Kế Test Cases

Chạy /generate_manual_testcases_rbt -> AI thực hiện quy trình RBT 6 bước và xuất ra bảng Test Cases hoàn chỉnh đạt tiêu chuẩn DoD.

3. Tạo Dữ Liệu Kiểm Thử (Test Data)

Chạy /generate_test_data cho form Đăng Ký -> AI tự sinh bộ dữ liệu email/số điện thoại dạng unique như test_register_1712049200@manual.test để tiện debug và không trùng lặp database.

Trợ Lý Log Bug Tự Động Với Jira Rovo Agent

Tích hợp và tự động hóa quy trình báo cáo lỗi di động trực tiếp trên Jira Rovo.

  • Nhận diện & Phân tích thông minh: Tự động phân tích lỗi từ hội thoại, crash logs, console logs hoặc API payloads.
  • Chuẩn hóa môi trường di động: Yêu cầu làm rõ OS version, device model, app build version và các bước tái hiện (Steps to Reproduce).
  • Tạo Bug Ticket tức thì: Tích hợp Jira Actions để tự động tạo ticket Bug chuẩn QA trên Jira sau khi nhận được xác nhận từ người dùng.
# ROLE & GOAL
- Assistant that speeds up the bug reporting and logging process.
- Analyze errors on mobile applications (iOS/Android) and format into Jira Bug tickets.
- Environment: Platform, Device, OS Version, App Build.
- Severity: Critical/Blocker, Major, Minor, Trivial.
- Call createJiraIssue (Type=Bug) after confirmation.
💡 Sao chép cấu hình System Instructions và bật Jira Actions (createJiraIssue) trong Rovo để triển khai ngay lập tức.
